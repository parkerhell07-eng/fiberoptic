# فیبرکار 🟢

**اپلیکیشن مدیریت پروژه‌های شبکه فیبر نوری — کاملاً فارسی، راست‌چین و آفلاین**
برای تکنسین‌ها، مجریان و پیمانکاران فیبر نوری.

## ✨ امکانات

| ماژول | شرح |
|---|---|
| 📁 **پروژه‌ها** | نام، کد، کارفرما، محدوده، تاریخ شروع شمسی، وضعیت، پیمانکار/مجری، آرشیو، حذف کنترل‌شده با زنجیره امن |
| 🛣️ **ساختار سلسله‌مراتبی** | پروژه ← مسیر شبکه ← باکس ← عملیات ← عکس‌ها |
| 🧰 **عملیات اجرایی** | بازدید، نصب باکس، آماده‌سازی کابل، فیوژن، تست توان، دراپ‌کابل، عیب‌یابی، تحویل + نوع سفارشی؛ مسئول با اسنپ‌شات نام/نقش |
| ⚡ **فیوژن** | شماره تارها، تیوب، کابل، شناسه اتصال، دستگاه (اختیاری)، **نتیجه عیناً ثبت‌شده** (بدون مقدار ساختگی)، عکس قبل/حین/بعد |
| 📡 **تست توان** | مقدار واقعی، dBm/mW، طول موج nm، دستگاه، عکس صفحه دستگاه؛ تبدیل dBm↔mW فقط برای **نمایش** با برچسب «محاسباتی» |
| 🔌 **دراپ‌کابل** | مبدأ/مقصد، شناسه سرویس، کابل، برند/مدل، کور، متراژ اولیه/برگشتی/مصرفی (کاربری هرگز بازنویسی نمی‌شود؛ محاسباتی فقط از ورودی معتبر)، روش اجرا، وضعیت نصب/تحویل، فیلتر و آمار مجموع |
| 👤 **پروفایل‌های کاری** | ۹ نقش + سفارشی، فیلدهای تخصصی متناسب با نقش، چند نقش همزمان |
| 📷 **مدیریت عکس** | دوربین/گالری دستگاه، ذخیره در فضای اختصاصی اپ (گالری عمومی آلوده نمی‌شود)، دسته‌بندی، پیش‌نمایش با زوم، ویرایش، حذف با تأیید، بندانگشتی برای صرفه حافظه |
| 📄 **گزارش PDF فارسی** | راست‌چین با حروف متصل، جدول‌ها، تصاویر با شرح، صفحه‌بندی و شماره صفحه، حالت خلاصه/کامل + انتخاب بخش‌ها و عکس‌ها، اشتراک‌گذاری اندرویدی |
| 🔍 **جست‌وجوی سراسری** | پروژه، باکس، مسیر، مسئول، شناسه کابل، بازه تاریخ شمسی، وضعیت، آرشیو |
| 💾 **پشتیبان‌گیری/بازیابی** | فایل JSON کامل (همه جدول‌ها + عکس‌ها + ارتباط‌ها)، checksum SHA-256، بررسی سلامت، نسخه‌بندی، بازیابی «جایگزینی کامل» یا «ادغام» با هشدار دو مرحله‌ای |
| 🌓 **حالت روشن/تاریک** | با next-themes؛ رنگ اصلی سبز فیبر نوری |
| 📲 **PWA** | نصب روی اندروید از مرورگر؛ Service Worker فقط در بیلد production |

## 🔒 حریم خصوصی

- **هیچ داده‌ای از دستگاه خارج نمی‌شود.** بدون سرور، بدون ثبت‌نام، بدون پرداخت، بدون همگام‌سازی.
- پایگاه داده: IndexedDB مرورگر/WebView (Dexie). عکس‌ها فشرده و با بندانگشتی ذخیره می‌شوند.
- توکن، کلید یا رمزی در سورس وجود ندارد.

## 🚀 اجرا

```bash
bun install
bun run dev        # http://localhost:3000
bun run lint       # ESLint
bunx tsc --noEmit  # بررسی تایپ
```

نصب روی گوشی اندرویدی (نسخه وب): با مرورگر باز کنید → منوی «افزودن به صفحه اصلی».
(نصب‌پذیری کامل PWA و کارکرد آفلاین پس از بیلد production فعال می‌شود.)

## 🧪 گزارش تست (اجرا شده با مرورگر واقعی)

همه سناریوهای اجباری مأموریت به‌صورت E2E اجرا و تأیید شدند — جزئیات در `worklog.md` (Task 4):
ایجاد پروژه/مسیر/باکس، ثبت عملیات با اسنپ‌شات مسئول، فیوژن + عکس، تست توان + اعتبارسنجی و تبدیل صحیح واحد،
دراپ‌کابل + بلاک منفی/برگشتی>اولیه، پروفایل و فیلدهای نقش‌محور، آپلود عکس، PDF فارسی ۲ صفحه‌ای با تصویر،
جست‌وجو، پشتیبان‌گیری + بررسی checksum، حذف رکورد و بازیابی بازگشتی آن، ماندگاری پس از reload،
کارکرد کامل بدون اینترنت، حالت تاریک، موبایل/دسکتاپ.

## ⚠️ محدودیت‌های شفاف

- **APK در همین محیط ساخته نشد** چون Android SDK/Gradle در دسترس نیست؛ ورک‌فلو و راهنما کاملاً آماده است.
- حروف PDF به‌صورت رندر مرورگری درج می‌شوند (متن PDF قابل انتخاب/جست‌وجو نیست) — برای اتصال صحیح فارسی این پایدارترین روش است.
- در حالت dev، رفرش صفحه با اینترنت قطع، خطای مرورگر می‌دهد (Service Worker عمداً فقط در production فعال است).

## 🏗️ معماری

```
src/
├─ app/                    # تک‌مسیر / — شل SPA با ناوبری هش
├─ components/fiberkar/    # ۱۴ نمای ماژول + primitives + photo-picker/gallery
├─ lib/
│  ├─ types.ts             # مدل داده
│  ├─ localdb.ts           # Dexie/IndexedDB + CRUD + حذف زنجیره‌ای + آمار
│  ├─ persian.ts           # تاریخ شمسی (jalaali-js)، ارقام فارسی، dBm↔mW
│  ├─ pdf.ts               # گزارش راست‌چین (html2canvas-pro + jsPDF)
│  ├─ backup.ts            # پشتیبان JSON + SHA-256 + بازیابی replace/merge
│  └─ labels.ts            # تمام برچسب‌های فارسی
└─ store/app-store.ts      # ناوبری Zustand + hash sync
```

نسخه‌های آینده آنلاین: لایه `localdb.ts` جدا از UI است؛ افزودن همگام‌سازی ابری صرفاً یک آداپتور جدید می‌خواهد.
