#### 🆕 تازه‌های نسخه ۱٫۲٫۰
- **مقیاس و ابعاد درست روی همهٔ گوشی‌ها**: اندازهٔ متن دیگر تحت تأثیر فونت/نمایش سیستم بزرگ‌نمایی نمی‌شود (مثل بقیهٔ اپ‌ها)، محتوا زیر نوار وضعیت و نوار ناوبری سیستم نمی‌رود و اپ دیگر «تمام‌صفحهٔ کش‌آمده» دیده نمی‌شود
- **PDF — فاصلهٔ جدول‌ها**: وقتی توضیحات/مشخصات فنی بلند می‌شود دیگر فاصلهٔ بزرگ بین جدول‌ها نمی‌افتد (جدول‌های مشخصات ردیف‌به‌ردیف شکسته می‌شوند و متن‌های بلند به تکه‌های متراکم)
- **PDF — شبکهٔ عکس‌ها**: عکس‌ها به‌جای پشته‌شدن و پرت‌شدن به صفحه‌های بعدی، مرتب دو‌به‌دو کنار هم در ارتفاع یکنواخت قرار می‌گیرند (بدون کجی/کشیدگی/بریدگی)؛ حدوداً ۶ عکس در هر صفحه
- **PDF — تیتر یتیم**: تیتر بخش‌ها دیگر تنها در انتهای صفحه رها نمی‌شود
- **حجم ۴۲٪ کمتر**: فعال‌سازی R8 و حذف منابع بلااستفاده (۵٫۲MB ← ~۳MB)
- **سخت‌سازی امنیتی**: ترافیک رمزنشده در سطح سیستم ممنوع (Network Security Config) — پروفایل تمیز برای Play Protect و آنتی‌ویروس‌ها؛ فقط مجوز INTERNET؛ امضای v2+v3

#### 🆕 تازه‌های نسخه ۱٫۱٫۰
- **گزارش PDF بازنویسی شد**: جدول‌های بلند دیگر هیچ سطری را گم نمی‌کنند (سرستون در هر صفحه تکرار می‌شود)، گزارش‌های چندصفحه‌ای با عکس زیاد روی گوشی‌های ضعیف کرش نمی‌کنند (رندر تک‌صفحه‌ای)، ترتیب واقعی داده‌ها، مقدار mW با دقت کامل (بدون صفرسازی فیک)، فیلدهای بیشتر در حالت کامل (ظرفیت باکس، برند/مدل/کور دراپ‌کابل، مجری و…)، پیشرفت مرحله‌ای، و اشتراک‌گذاری اندرویدی صادقانه (خطا دیگر به‌عنوان موفقیت نمایش داده نمی‌شود)
- **مقاوم‌سازی داده**: بازیابی «جایگزینی کامل» اتمی شد (قطع وسط کار = هیچ داده‌ای نمی‌پرد)، عکس‌ها در جدول جداگانه ذخیره می‌شوند (لیست‌ها دیگر با گالری‌های بزرگ کرش/OOM نمی‌کنند)، حذف‌ها عکس‌های یتیم نمی‌گذارند، ویرایش هر رکورد لینک عکس‌هایش را هم‌زمان می‌کند
- **ناوبری درست**: دکمه Back اندروید و دکمه بازگشت اپ همیشه هم‌رفتارند؛ بعد از حذف رکورد، Back به رکورد حذف‌شده برنمی‌گردد؛ لینک‌های عمیق (مثل جست‌وجو) فرم ویرایش را خودکار باز می‌کنند
- **داشبورد پیشرفته**: نمودار روند عملیات ۶ ماه شمسی اخیر، توزیع وضعیت پروژه‌ها، «عملیات این ماه» با ماه شمسی صحیح، یادآور پشتیبان‌گیری بر اساس عمر آخرین پشتیبان
- **خروجی CSV/اکسل**: عملیات، دراپ‌کابل و تست توان با سرستون فارسی و BOM — مستقیم در اکسل باز می‌شود
- **سلامت داده‌ها**: اسکن خودکار عکس‌های یتیم، رکوردهای بدون والد، مغایرت متراژ و وضعیت‌های ناشناخته + پاک‌سازی یک‌ضربه‌ای عکس‌های یتیم؛ نمایش مصرف فضای ذخیره‌سازی
- **جست‌وجوی هوشمندتر**: نرمال‌سازی فارسی (ی/ي عربی، نیم‌فاصله، ارقام)، جست‌وجوی چندواژه‌ای (AND)، جست‌وجو در عکس‌ها، سقف رندر هر گروه + «نمایش بیشتر»
- **سنجاق پروژه‌ها** (Pin) در لیست و داشبورد؛ میان‌بر صفحه‌کلید «/» برای جست‌وجو؛ اعلان به‌روزرسانی PWA؛ رفع ده‌ها باگ ریز فرم‌ها (پاک‌شدن میانی فیلد عددی، نام مجری مانده روی رکورد، دکمه حذف فوکوس‌شده با Enter، و غیره)

## 🔒 حریم خصوصی

- **هیچ داده‌ای از دستگاه خارج نمی‌شود.** بدون سرور، بدون ثبت‌نام، بدون پرداخت، بدون همگام‌سازی.
- پایگاه داده: IndexedDB مرورگر/WebView (Dexie). عکس‌ها فشرده و با بندانگشتی ذخیره می‌شوند.
- توکن، کلید یا رمزی در سورس وجود ندارد.

## ⚠️ محدودیت‌های شفاف

- نصب APK روی گوشی فیزیکی/شبیه‌ساز در این سندباکس ممکن نبود (دستگاه اندرویدی در دسترس نیست)؛
  صحت بسته‌بندی با `aapt`/`apksigner` تأیید شده و وب‌اپ داخل آن با همان کدِ تست‌شده E2E ساخته شده است.
- حروف PDF به‌صورت رندر مرورگری درج می‌شوند (متن PDF قابل انتخاب/جست‌وجو نیست) — برای اتصال صحیح فارسی این پایدارترین روش است.
- در حالت dev، رفرش صفحه با اینترنت قطع، خطای مرورگر می‌دهد (Service Worker عمداً فقط در production فعال است).

## 🏗️ معماری

```
src/
├─ app/                    # تک‌مسیر / — شل SPA با ناوبری هش
├─ components/fiberkar/    # ۱۴ نمای ماژول + primitives + photo-picker/gallery
├─ lib/
│  ├─ types.ts             # مدل داده
│  ├─ localdb.ts           # Dexie/IndexedDB + CRUD + حذف زنجیره‌ای + آمار
│  ├─ persian.ts           # تاریخ شمسی (jalaali-js)، ارقام فارسی، dBm↔mW
│  ├─ pdf.ts               # گزارش راست‌چین (html2canvas-pro + jsPDF)
│  ├─ backup.ts            # پشتیبان JSON + SHA-256 + بازیابی replace/merge
│  └─ labels.ts            # تمام برچسب‌های فارسی
└─ store/app-store.ts      # ناوبری Zustand + hash sync
```

نسخه‌های آینده آنلاین: لایه `localdb.ts` جدا از UI است؛ افزودن همگام‌سازی ابری صرفاً یک آداپتور جدید می‌خواهد.
